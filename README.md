# Sabi

Sabi adalah teman kecil berbentuk bulan sabit yang membantu mengatur
harimu: jadwal sholat dan pengingat ibadah, habit, gym, waktu layar,
gempa dan cuaca dari BMKG, dan lainnya. Semua datamu tersimpan di HP-mu
sendiri, tanpa akun.

Repositori ini hanya berisi file APK. Kode sumbernya private.

## Memasang

1. Buka [Releases](https://github.com/Leuthra/sabi-releases/releases/latest).
2. Unduh `sabi-<versi>-arm64-v8a.apk`. Untuk HP lama 32-bit, pilih
   `armeabi-v7a`.
3. Buka file-nya. Kalau Android meminta izin memasang dari browser atau
   pengelola file, izinkan sekali saja.

## Memperbarui

Sabi mengecek versi baru dengan sendirinya dan menampilkan pemberitahuan
di Beranda. Ketuk, unduh, lalu buka file-nya dan pilih **Perbarui**.
Datamu tetap ada.

Bisa juga memakai aplikasi [Obtainium](https://obtainium.imranr.dev/)
dengan alamat repositori ini.

## Keamanan

Setiap rilis ditandatangani dengan kunci yang sama. Sidik jari sertifikat
(SHA-256):

```
AD:42:BA:2B:04:DF:45:DD:A0:5F:63:AF:9E:66:FC:63:B0:BD:1C:E4:68:6A:66:8E:CD:0B:AB:87:FB:0C:C4:E8
```

`SHA256SUMS.txt` di setiap rilis berisi checksum untuk memeriksa file APK.
